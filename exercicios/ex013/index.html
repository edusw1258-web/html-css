Introdução

1.1 - Estilos CSS

As configurações de estilo nas CSS permitem controlar a aparência e o layout dos elementos HTML de forma flexível e eficiente.

1.2 - Formas de aplicação nas CSS

É possível aplicar estilos nas CSS de três maneiras: inline, internos e externos.

Inline

Aplicado diretamente ao elemento, via atributo style, dentro da tag de abertura do elemento HTML.

<p style="color: red;"></p>

Interno/Local

Aplicado dentro do documento HTML, via elemento <style>

<style> p { color: red; } </style>

Externo

Aplicado em um arquivo CSS separado, referenciado no documento HTML via elemento <link>

<link rel="stylesheet" href="estilos.css">
