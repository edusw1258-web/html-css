<strong>

Nesta outra parte temos um outro trecho destacado em negrito usando uma tag semântica.

Itálico / Ênfase

<i>

Aqui temos um trecho em itálico usando uma tag não semântica.

<em>

Aqui temos uma outra maneira de destacar um trecho em itálico, usando uma tag semântica.

Texto marcado

<mark>

Podemos marcar um trecho usando a tag 'mark', como aqui.

<mark>

Também é possível mudar a cor da marcação como aqui.

Texto grande e texto pequeno

<big>

Este texto está em tamanho grande com o uso da tag 'big'.

<small>

Este texto está em tamanho pequeno com o uso da tag 'small'.

Texto deletado

<del>

Podemos marcar um texto como excluído para indicar que ele pode ser lido mas não deve ser considerado.

Texto inserido

<ins>

Podemos marcar um texto como inserido para indicar que ele foi adicionado posteriormente.

Texto sobrescrito

<sup>

A tag 'sup' é usada para sobrescrever um texto, exemplo: x2+4

Texto subescrito

<sub>

A tag 'sub' é usada para subescrever um texto, exemplo: H2O
