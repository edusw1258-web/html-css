Exercício 004 - Favicon

Favicon

Favicon é o icone referente à páginaque aparece na aba do navegador. Para adiconá-lo basta adicionar um link para uma imagem que seja uma favicon dentro da área head no documento HTML.

Para acessar o repositório gratuito de icons acesse:

www.iconarchive.com
