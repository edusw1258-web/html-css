Exercício 006 - Títulos e subtítulos

Títulos e subtítulos usando as tags de <h1> a <h6>

<h1> - Título principal

Utilizamos a tag <h1> para títulos principais que se referem a página inteira. O ideal é ter apenas um <h1> por pagina ou por seção.(header, main, footer).

<h2> - Título de seção

Utilizamos a tag <h2> para títulos de seções dentro de uma mesma página ou como subtítulos. de <h1>.

<h3> - Título de artigo

Utilizamos a tag <h3> para títulos de artigos e temas ou como subtítulos de <h2>.

<h4> - Título de subtítulo

Podemos ainda utlizar as tags de <h4> a <h6> para subtítulos das tags anteriores.

<h5> - Título de subsubtítulo

Podemos ainda utlizar as tags de <h5> a <h6> para subtítulos das tags anteriores.

<h6> - Título de subsubsubtítulo

Podemos ainda utlizar as tags de <h6> para subtítulos das tags anteriores.
