Exercício 011 - Imagens dinâmicas

1Imagens dinâmicas

O navegor identifca cada <source> de cima para baixo. A primeira condição determina a imagem. O <img> é o fallback final e quem efetivamente renderiza a imagem

2Reproduzindo áudio

// Duas maneiras para inserir um áudio

Método 1 - Atributo SRC

src diretamente na tag <audio>

control autoplay

Método 2 - Elemento Source

<source> dentro do audio - permite adicionar elementos alternativos

control autoplay preload="auto"
